# PRO-side sweep (2026-11-14)

A deep sweep of the NBD Pro CRM (contractor side only: `docs/pro/`, `functions/`, `firestore.rules`, `storage.rules`, `tests/`), run after the [2026-11-06 overnight UI audit](../../overnight/crm/MORNING_REPORT.md). That audit's 247 findings were excluded; this sweep looked at what it did not cover: tenant isolation in the rules, Cloud Function auth, Stripe and the ledger, the messaging kill switch, money records, and whether the security tests can fail.

**How:** six read-only reviewers in parallel (rules, functions auth, payments, silent failures, click paths, vacuous tests), each finding checked against the code before any fix. Every fix has a test shown to fail on main first. All fixes then went through a security review and a reality check. Nothing was merged or deployed.

**Live code:** this repo. `nbdpro-v3` is archived ("v1 chosen as the final product").

## Process notes for the next session

- The node manifest runner stops at its 8-minute budget locally; run the suites a change touches by name.
- Never pipe a test through `tail` inside an `&&` chain: `tail` exits 0 and the chain carries on past a red test. It happened once here (fixed before push).
- Emulator rules suite: about 4 minutes each way; prove new assertions red on main's rules before trusting them.
