# Repo Lab: what Jo's screenshotted repos, skills and tools are worth (2026-10-01)

Every repo, Claude skill, plugin, MCP server and developer tool named in the triaged screenshot list (209 rows at the time), plus 3 new ones found in the untriaged `n2/` batch (UI UX Pro Max, JARVIS, Fish Audio). The last 39-screenshot batch was triaged after this ran. GitHub stats came from the GitHub API (`gh api repos/...`) on 2026-10-01. READMEs were read from source. Nothing was installed, cloned or run. Repo checks were read-only.

**Verdicts.** ADOPT = install or use it. BORROW = copy the idea or pattern, not the code. LEARN = understand it, no action. AVOID = don't touch. SKIP = not relevant.

**Two facts shape every reskin verdict:**
- The CRM CSP has no CDN in `script-src`: only `'self'` plus Google, Stripe and Sentry hosts (`firebase.json`). Any animation or shader library has to be **vendored as a file under `docs/`**, or written by hand. React-only libraries (React Bits, ShaderGradient, Aceternity, Skiper) cannot be dropped in.
- The wallpaper engine already exists and is now live. `ThemeEngine.apply()` calls `ThemeOverlays.apply(theme.overlay)` (`docs/pro/js/theme-engine.js:5472`). `theme-overlays.js` checks `prefers-reduced-motion` (line 174). `shape-preboot.js` stamps `data-shape`. So Phase 0 and Phase 1 of the 09-08 Appearance Lab plan (`documentation/projects/SESSION-2026-09-08-appearance-lab-exploration.md`) have landed. Any new background effect should be **one more overlay type in `theme-overlays.js`**, not a new library.

- Jev is **not waitlist-only**. It is in public beta on OpenRouter as `typesafe/jev-1.13`.

## Per-item notes

### Prompt Master: BORROW
- Source: https://github.com/nidhinjs/prompt-master. MIT, 13.9k stars, last push 2026-08-24. The whole repo is `SKILL.md` plus `references/patterns.md` and `templates.md`, with no scripts. The reel was accurate: target-tool routing, 9 intent dimensions, at most 3 clarifying questions.
- Its own hard rules are sensible: no hidden chain-of-thought requests, no fake "tree of thought" in single prompts.
- **Concrete payoff:** run the Ask Joe system prompt (`docs/pro/js/ai.js:125-152`) through the 9 dimensions. It has task, context, audience and output style, but **no constraints and no success criteria**.
- It also tells Joe he knows "adjuster negotiations" and should write a "letter to adjuster" with no Kentucky guardrail. That conflicts with the Kentucky insurance-job rule in memory (no "we handle/negotiate the claim").
- It also lacks a "never invent numbers not in the context block" rule.
- Same checklist for `functions/voice-prompts.js` (`buildAnalyzePrompt`).
- Installing it is optional. Claude.ai upload is the README's recommended route. In Claude Code it would only fire when asked to write a prompt.

### Impeccable: ADOPT (skill only, hook off first)
- Source: https://github.com/pbakaus/impeccable, docs at https://impeccable.style. Apache-2.0, 73k stars, pushed 2026-10-01. It started from Anthropic's frontend-design skill.
- `/impeccable init` writes `PRODUCT.md`; `/impeccable document` generates `DESIGN.md` from existing code.
- Commands such as `critique`, `audit`, `polish`, `layout`, `typeset`, `quieter` and `bolder` give the "more vertical rhythm" vocabulary the reel promised.
- 61 deterministic detector rules run with no LLM and no API key.
- **Safety:** the launcher downloads a pinned engine binary to `~/.impeccable/bin/` on first run. `npx impeccable install` adds a hook to `.claude/settings.local.json` that runs on every UI file edit and on Stop. The README itself warns that hooks run outside model-tool approval.
- Install with `--no-hooks --scope=project` in a short-path worktree first (`C:\Users\jonat\nbd-wt-<name>`). Only enable the hook after a dry run.
- **Reskin fit:** its anti-patterns (no Inter-for-everything, no nested cards, tinted not pure grays) are the right critique lens. CSP and partial gates still apply, so check that every suggestion lands in external CSS/JS.

### Awesome DESIGN.md: ADOPT the format

- The repo has **no DESIGN.md** (git ls-files); there are only audits (`documentation/audit/DESIGN-CONSISTENCY-SWEEP-2026-08-19.md`, `THEME_SYSTEM_AUDIT_2026-06.md`).
- A CRM DESIGN.md should name:
  - the token source (`docs/pro/css/theme-system.css`, `theme-bridge.css`)
  - the three orthogonal attributes `data-theme` / `data-density` / `data-shape`
  - the overlay contract (`theme-overlays.js`)

  - the phone-first rule
- Highest-leverage, lowest-risk item on this list.

### Ponytail: BORROW the rule
- Source: https://github.com/DietrichGebert/ponytail. MIT, 149k stars, v4.10.0.
- Claim, from its own benchmark: about 54% less code, measured on 12 tasks with Haiku 4.5 at n=4. The README itself walks back older 80–94% figures. That's honest, but still self-measured.
- The Claude plugin declares `hooks/claude-codex-hooks.json`, which runs activator, mode-tracker and statusline JS.
- This repo already works in thin, gate-tested slices. Just add the core rule to CLAUDE.md: "native element or stdlib before a library, never cut validation, a11y or security". It fits the vanilla CRM perfectly (`<input type="date">` over a picker library).

### BASE (ChristopherKahler/base): LEARN, AVOID install
- Source: https://github.com/ChristopherKahler/base. 266 stars. Functional Source License 1.1, which is not open source until it converts to Apache.
- Installs with `curl | sh` or `irm | iex`. It wires hooks into **global** `~/.claude/settings.json`, and every session start checks for a new release and **installs it in a detached background process**. That is silent, unreviewed code execution in every session, the same supply-chain shape the gates exist to prevent.
- What to borrow: "session start lands the open handoff". A local `SessionStart` hook that prints the current handoff path from `documentation/INDEX.md` (the `**Current handoff:` pointer) gets 80% of the value with zero third parties.

### fast-jev-compaction and claude-x-jev: LEARN; AVOID compaction
- Sources: https://github.com/tamaratran/fast-jev-compaction (MIT, 7.3k stars) and https://github.com/charlesdove977/claude-x-jev (MIT, 22 stars).
- Jev: https://openrouter.ai/blog/insights/what-is-jev/ and https://openrouter.ai/docs/guides/community/jev-tutorial. Jev is TypeSafe's "decision model" in OpenRouter beta: choice, yes/no and score answers with confidence, about $0.042 per million input tokens, output free.
- The compaction plugin sends **the whole conversation**, with tool inputs and results replaced by short notes, to `https://api.typesafe.ai/v1/systemone` using `TYPESAFE_API_KEY`. On this repo that means CRM code and customer-data snippets going to a new vendor.
- The useful lesson: built-in compaction *summarizes* (lossy). This plugin *deletes* stale tool results and keeps everything else verbatim. Jo's handoff notes and memory files are the right human-side mitigation already.
- claude-x-jev's `/jev-gate` auto-approves tool calls by a 0.3-second classifier. Don't let a third-party classifier gate permissions.

### Motion, React Bits, ShaderGradient, shaders.com (reskin special interest)
- **Motion**: https://github.com/motiondivision/motion (MIT, 33.8k stars) and https://motion.dev/docs/quick-start.
  - Vanilla `animate()` (the mini version is about 2.3 kb), `scroll()`, `hover()`, springs and `stagger()`. It works without React.
  - The CSP allows no CDN, so vendor the ESM file under `docs/pro/js/vendor/` and load it with `defer`.
