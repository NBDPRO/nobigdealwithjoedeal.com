## The flag

`docAtticAckV1`, per person (`feature_flags/_default` or `feature_flags/{uid}`, only boolean `true` is on), **default OFF**, in `functions/flags-registry.js` `FIRESTORE_FLAGS`. Off: every path behaves as before (the phase 2 golden hashes still pass). Turn on together with `docEvidenceFoundation` and `docClauseSetV1`; the server reads it strictly (a read error refuses).

## Data model

- `leads/{id}.scope`: `reroof | repair | siding | gutters | other`. Default from the primary estimate (any row/line with code `LAB TO...` = reroof; `workKind` repair = repair; else other); the rep's explicit choice wins. No pricing change.
- `leads/{id}.atticCheck` (rep-written): `status` inspected | not_inspected, `reason` (declined, scheduling_homeowner, scheduling_nbd, no_access, unsafe, no_attic, other), `who` (homeowner | nbd | conditions), `reasonText`, `notes`, `inspectedOn`, `accessPoint`, `conditions{key:true}`, `conditionOther`, `vent{...}`, `recs[{id,qty}]`, `photos[{id,kind}]` (photo ids in the CRM photo collection, tagged `attic`), `version`, `recordedBy`, `recordedAt`. Q69 minimums are enforced by `validate()`.
- Signed form: a `leads/{id}/documents` row of type `attic_acknowledgment` or `attic_not_inspected`. **`atticAckResult`** (server-owned in `firestore.rules`): `{version, notInspected, declined, complete, acknowledgments[{id,checked}], formDateMs}`. `signatureEvidence.acknowledgments` carries the same ticks.
- `attic_overrides/{id}` (write:false in rules): `{leadId, companyId, byUid, byName, reason, scope, at, version}`, written only by `recordAtticOverride`.

## Deviation: ticks instead of initials

The generated-HTML signing paths only support signature canvases. The homeowner's Yes/No per line and each acknowledgment are **required tick controls** (`data-nbd-ack`), recorded with the signature, not initials. The signature widget refuses to finish with a missing tick; the server re-checks (remote: from the original document plus the submitted tick states; in-person: from the stored signed copy) and records every tick. The printed form carries one neutral line: "Tick each box and each Yes or No. Your ticks are saved with your signature." Counsel should confirm ticks plus signature suffice; the packet says "initials".

## Q18 override

`recordAtticOverride` (callable): company owner, `company_admin` of the same company, or platform admin only; reason 10 to 500 characters. A sent but unsigned form is notice, never signed; only a signed form with a server result, or an override, clears the gate.
