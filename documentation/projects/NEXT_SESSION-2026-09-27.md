## §3 Lessons (also in memory)

- **The repo is public.** Real customers' names and addresses went into fixtures, a vault note and 3 squash-commit messages. The tree and the PR bodies are scrubbed. Jo chose to leave git history alone. **Fixtures are fictional from the start;** acceptance checks against real people take `--expect` flags at run time.
- **Never put Markdown with backticks inside a double-quoted Bash string.** Bash ran them as command substitutions and mangled a vault note. It also launched a real script with a garbage argument, which exited harmlessly. Write edit scripts to files.
- **Bland v2 agents:**
  - The pathway is compiled from the agent. The number's own voice fields are placeholders; the persona owns the calls.
  - The Initialization step is not run on voice.
  - Memory greets before the prompt runs.
  - A number-webhook POST normalises `custom_tools: null` → `tools: []` (harmless).
